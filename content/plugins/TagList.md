该插件将当前页面的所有 Tags 标签渲染为横向可点击的链接药丸。每个标签直接链接到其对应的 [[TagPage|标签聚合页]]，方便读者按主题主题聚类浏览相关内容。

> [!note] 提示
> 关于如何添加、移除或配置插件，请参阅 [[configuration#插件体系（Plugins）|配置]] 页面。

该插件无额外配置选项。

## API

- 类别：组件（Component）
- 函数名：`ExternalPlugin.TagList()`
- 源码：[`quartz-community/tag-list`](https://github.com/quartz-community/tag-list)
- 安装：`npx quartz plugin add github:quartz-community/tag-list`
