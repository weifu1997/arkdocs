双向链接（Wikilinks，简称双链）最早由早期互联网维基系统提出，目的是让创作者能够极其自然地在笔记之间建立交织链接，而不必每次繁琐地编写完整的 Markdown 或 HTML 链接语法。

Quartz 默认完整支持双链，这些链接由 [[CrawlLinks]] 插件自动解析。更多关于双链的语法细节亦可参考 [Obsidian 内部链接官方文档](https://help.obsidian.md/Linking+notes+and+files/Internal+links)。

该功能作为 [[Obsidian compatibility|Obsidian 兼容特性]] 的核心部分，可在对应插件中配置启用或禁用。

为了与 Obsidian 保持完全一致的体验，双链匹配是**不区分大小写**的：例如 `[[My Note]]`、`[[my note]]` 和 `[[MY NOTE]]` 都会精准解析到同一个目标文件。生成的网页 URL 则统一转换为小写标准 Slug（例如 `my-note`）。

## 双链语法

- `[[文件路径]]`：生成指向目标 `文件路径.md` 的链接，文本显示为 `文件路径`；
- `[[文件路径 | 自定义显示文本]]`：生成指向 `文件路径.md` 的链接，文本自定义显示为 `自定义显示文本`；
- `[[文件路径#小标题锚点]]`：生成直达目标文件中 `#小标题锚点` 位置的锚点链接；
- `[[文件路径#^block-ref]]`：生成指向目标文件中具有 `^block-ref` 块引用 ID 的精确块链接。

### 嵌入语法（Embeds / Transclusions）

在双链前面加上感叹号 `!` 即可实现内容嵌入：

- `![[图片路径]]`：在当前页面中嵌入并展示图片；
- `![[图片路径|100x145]]`：以指定尺寸（宽 100px，高 145px）嵌入并展示图片；
- `![[文件路径]]`：将目标页面的完整内容嵌入当前页面；
- `![[文件路径#小标题锚点]]`：将目标页面指定小标题下的全部段落内容嵌入当前页面；
- `![[文件路径#^b15695]]`：仅嵌入带有 ID 为 `^b15695` 的单一片段/段落块。
